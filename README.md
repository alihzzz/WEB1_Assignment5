## 🚀 Features & Structure

The project is structured into 4 separate interactive pages connected via a top navigation bar (Navbar):

### 1. Part 1: Introduction to JavaScript (`index.html` & `script1.js`)
* **Task 0 (First Script):** Displays an alert message (`"Hello, JavaScript World!"`) and logs student details (Name and Group) into the browser console.
* **Task 1 (Variables & Operators):** Demonstrates data types (`string`, `number`, `boolean`), arithmetic operations (`+`, `-`, `*`, `/`, `%`), and string concatenation.

### 2. Part 2: DOM Manipulation (`part2.html` & `script2.js`)
* **Task 2 (Changing Content):** Modifies paragraph text upon clicking a button.
* **Task 3 (Changing Styles):** Dynamically alters the background color (randomized) and font size of a content box.
* **Task 4 (Creating & Removing Elements):** Dynamically appends (`Add Item`) and removes (`Remove Item`) list items (`<li>`) from a list (`<ul>`).

### 3. Part 3: Events (`part3.html` & `script3.js`)
* **Task 5 (Mouse Events):** Changes block background color and text when hovering over (`mouseover`) and restores default state on mouse exit (`mouseout`).
* **Task 6 (Keyboard Events):** Captures real-time text input using the `keyup` event and displays it immediately on the page.
* **Task 7 (Calculator):** A functional calculator performing addition, subtraction, multiplication, and division with zero-division safety handling.

### 4. Part 4: Mini Project — Interactive To-Do List (`part4.html` & `script4.js`)
* **Task 8 (To-Do App):** An interactive task management page featuring:
  * Adding tasks with title and detailed description.
  * Temporary task storage inside a JavaScript Array.
  * Task completion toggle with a strike-through text effect (`line-through`).
  * Deleting tasks from the list.
